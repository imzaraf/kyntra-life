# Flaticon icons

Download each icon from https://www.flaticon.com/icons as **SVG** (single colour works best,
since it is tinted to the theme) and save it here with these names:

| File        | Used for             |
| ----------- | -------------------- |
| today.svg   | Today tab            |
| journal.svg | Journal tab          |
| plan.svg    | Plan tab             |
| library.svg | Library tab          |
| capture.svg | Quick capture button |

Then uncomment the names in `lib/icons/flaticon.ts`. Flaticon's free licence requires
attribution — keep the credit line in the app/README as Flaticon instructs.
